Amazon Product Sales Analysis Dashboard
About This Project

In this project, I worked with an Amazon product dataset and created an interactive dashboard using Power BI and Python (Jupyter Notebook).
The main idea of this project was to understand how different products are performing based on their ratings, reviews, price, and discounts.

Dataset Information
The dataset includes useful information such as:
Product ID
Product Name
Category
Price
Discount Percentage
Rating
Number of Reviews

Before building the dashboard, I cleaned the dataset using Python.
Data Cleaning

Some values in the dataset were not in the correct format, so I fixed them by:
Removing % from discount percentage
Converting price columns into numbers
Converting rating into decimal format
Removing commas from review count
Handling missing values

This helped me create accurate charts in both Python and Power BI.

Dashboard Features
KPI Cards

The top section of the dashboard shows:
Total Products
Average Rating
Average Discount %
Total Reviews
Total Price

These KPIs give a quick overview of the dataset.

Visualizations Used
I created different charts to understand the data better:
Category-wise Product Count
Price vs Rating Scatter Plot
Good vs Bad Product Comparison
Discount Analysis
Product Table with Images
Category Charts

Product Classification
I also grouped the products into two types:
Good Products → Rating 4 and above
Bad Products → Rating below 4

This made it easier to compare product performance.
